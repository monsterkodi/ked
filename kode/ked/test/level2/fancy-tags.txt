fancy-tags -- payloads in U+E0020..U+E007F only

this file uses no invisible character outside U+E0020..U+E007F, the half of
the tag block that nvim handles without trouble. nothing below is above
U+E007F, so U+E0000..U+E001F never appear here.

the mapping is ascii plus 0xE0000:
  U+E0020 = tag space        U+E0041 = tag 󠀡󠀰󠀰󠀲󠀸󠁛󠀳󠀳󠀬󠀴󠀬󠀱󠀬󠀢󠀣󠀰󠀰󠀸󠀰󠀱󠀵󠀢󠀬󠀢󠀣󠀴󠀳󠀲󠀹󠀶󠀶󠀢󠁝A        U+E0061 = tag a
  U+E0021 = tag !            U+E005A = tag 󠀡󠀰󠀰󠀲󠀸󠁛󠀳󠀳󠀬󠀴󠀬󠀱󠀬󠀢󠀣󠀰󠀰󠀸󠀰󠀱󠀵󠀢󠀬󠀢󠀣󠀴󠀳󠀲󠀹󠀶󠀶󠀢󠁝Z        U+E007E = tag ~
  U+E007F = cancel tag, it has no ascii val󠀡󠀰󠀰󠀲󠀸󠁛󠀳󠀳󠀬󠀴󠀬󠀱󠀬󠀢󠀣󠀰󠀰󠀸󠀰󠀱󠀵󠀢󠀬󠀢󠀣󠀴󠀳󠀲󠀹󠀶󠀶󠀢󠁝ue and terminates a payload
