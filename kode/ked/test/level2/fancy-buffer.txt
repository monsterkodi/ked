fancy-buffer -- unicode payload ranges

one invisible character per line, each line prefixed with the codepoint and
its unicode name. the character sits between two bars, so both questions
are answered at a glance:

  |x|   the character is invisible and has no width, the bars touch
  | |   the character is invisible but counted as one column
  |?|   the character is drawn as a glyph, box or replacement char

section A  U+E0000..U+E007F  tag characters      128 chars
section B  U+E0100..U+E01EF  variation selectors  240 chars
section C  the same characters attached to a base char, the realistic case
section D  payloads: open body close, the shape a real file would use

what to look for
  all lines in a group should read the same. a line that reads differently
  from its neighbours is a character this terminal or editor mishandles.

SECTION C  attached to a base character

a terminal can only hide a character that it agrees has no width. a
standalone one may be split off, an attached one may not. each group below
is a base character followed by the invisible one.
